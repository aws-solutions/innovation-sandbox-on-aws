---
title: Edit access and sharing
---

Configure lease sharing and the permission sets available to leases created from this template.

---

## Lease sharing

Turn on **Allow owner to share lease** to let a lease owner manage user and group access. When it is off, only Admins and Managers can manage assignments.

When lease sharing is turned off in the solution settings, you cannot turn this option on. If it was enabled previously, the control remains available so you can turn it off.

---

## Permission sets

Add up to 20 permission sets that can be selected for individual users and groups. The selected-permission-sets table shows each description and identifies the current default. Choose **Set as default** in the table to change it. The current default cannot be removed until another selected permission set replaces it.

Removing a non-default permission set prevents it from being selected on future leases created from the template.

---

## When changes apply

Template changes apply only to leases created after you save. Existing leases keep the access settings captured when they were created.
