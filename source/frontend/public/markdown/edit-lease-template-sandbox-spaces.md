---
title: Edit Sandbox Spaces
---

Control the Sandbox Spaces AI chat for leases created from this template.

---

**Sandbox Spaces**: When enabled, users with a lease from this template can use the Sandbox Spaces AI chat to act on their sandbox account. Agent (chat) spend counts toward the lease budget. Bedrock token monitoring is required while Sandbox Spaces is enabled, so enabling Sandbox Spaces turns it on. When you disable Sandbox Spaces, monitoring stays on, and you can turn it off in the budget settings. If Allow Bedrock token monitoring is off in Settings, disabling Sandbox Spaces also turns monitoring off.

**Limit available models**: Off by default, so users can choose any model an administrator enables in Settings, including ones enabled later. Turn it on and use **Add models** to restrict this template's leases to the models you add; at least one model is needed.

**Default model**: The model selected when a user first opens the Space. Choose **Set as default** in the models table. With the limit on, the default must be one of the added models. A default that has since been disabled in Settings shows as Disabled; remove it or set another default.

---

_Note: Changes apply to new leases only. Existing leases keep the Sandbox Spaces settings they were created with; a manager or administrator can change an individual lease's settings from its lease details page._
